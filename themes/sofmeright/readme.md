### Notes
Version 2.0 retires the magenta half of the original gradient. Green text over
the bright end measured 3.25:1, below the 4.5:1 needed for body text, and the
brightest part of the sweep sat behind the navigation bar. The ground is now
eggplant throughout, shaded for depth rather than hued, which leaves the green
as the only saturated colour on the page.

Also corrected in 2.0: links were periwinkle (#7581cc) and code blocks were
styled for a light page (#F1F1F1 background), both inherited from flare and
both wrong on a dark theme — the code styling measured 2.11:1. Every colour now
resolves through the palette in :root instead of being repeated as literals
across four files.
